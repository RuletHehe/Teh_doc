Система обработки обращений технической поддержки
Классификация инцидентов
Все обращения разделяются по степени важности на 4 категории:

Критический уровень

Блокировка бизнес-процессов
Существенная деградация сервисов
Угроза конфиденциальности и целостности данных
Нарушения законодательства в области защиты информации
Высокий уровень

Существенная деградация работы компонентов и сервисов
Средний уровень

Незначительная деградация работы
Сервисы функционируют штатно
Низкий уровень

Обнаружение несущественных ошибок
Проблемы, не влияющие на работу системы
Специальные типы обращений
Service Request — запросы на поддержку сервисов (создание, изменение, включение/выключение настроек)
Request for Information — консультации по работе сервисов
Оба типа относятся к обращениям низкого приоритета.

Сроки обработки
Время реакции — не более 60 минут с момента регистрации обращения
Сроки решения (95% обращений):
Критические — до 2 часов
Высокие — до 12 часов
Средние — до 24 часов
Низкие — до 48 часов
Важно: все указанные сроки рассчитываются в астрономических часах с момента уведомления клиента о регистрации обращения.
